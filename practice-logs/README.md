# Coding 复健日志

这里保存练习后的简短总结，供本人回看、其他 AI 接手及精选概念卡片使用。

长期指导约定见 [LEARNING_GUIDE.md](../LEARNING_GUIDE.md)，当前能力证据摘要见 [LEARNER_STATE.md](../LEARNER_STATE.md)。接手时同时读取最近日志与相关代码。

- 每天一个 `YYYY-MM-DD.md`；同一天有多次练习，追加到当天文件。
- AI 根据真实对话与代码生成记录，学习者核对；记录不额外增加五分钟练习的负担。
- 保留任务、代码位置、实际表现、参考与帮助、概念收获、验证结果和下一次观察点。
- 分清本人实现、参考实现、本人报告及实际验证。没有核验的提交、用时和能力明确标注。
- 有未解决的问题就如实保留；概念卡片每次至多精选两张，不需要每天凑数。
- 日志与代码一起阅读，不能只凭文字总结判断整体水平。

简短模板：

```text
任务与代码：
完成情况及验证：
参考与帮助：
今天多会的一件事：
待确认或未解决：
下一次观察点：
可选概念卡片（最多两张）：
```

练习代码继续放在 `solutions/`，这里的日志不参与 Codewars 解题数量统计。提交和 push 由学习者决定。
