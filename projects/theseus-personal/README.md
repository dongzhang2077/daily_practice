## 第一项实现：显示用的秒数计算

2026-11-06：本人已实现，并在 Review 的向下取整方向提示后修正；三个已有检查均通过。当前完成范围为这个纯计算模块，计时界面和保存恢复仍待实现，详细过程见 [当日日志](../../practice-logs/2026-11-06.md)。

按未另选时间时的默认五分钟任务准备，可以由本人明确选择更长时间继续。

打开 [src/elapsed_time.js](src/elapsed_time.js)，补全 getElapsedSeconds(startedAtMs, currentTimeMs)。

- 两个参数都是毫秒时间戳，且 currentTimeMs 大于或等于 startedAtMs。
- 返回已经过去的完整秒数；不足一秒的部分舍去。
- 输入相同返回 0。
- 不在函数内读取当前时间，让调用者传入，便于模拟经过时间并验证。
- 本轮只处理合法数字；不要求异常输入、暂停、持久化或界面刷新。

例子：getElapsedSeconds(10000, 15000) 应为 5；getElapsedSeconds(10000, 15900) 也应为 5。

完整秒只是当前显示辅助函数的返回约定，不代表原始时间戳丢弃毫秒，或整款产品的精度已最终确定。后续真实计时与恢复可复用这个小模块。
